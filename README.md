# 輪印防線 試玩版

Godot 網頁試玩，不含原始碼。來源版本：master `2297d17`（含商店卡死修正、進化費用、難度平滑、階段 4 選關與 4-D／4-E、第 1–3 關校準、get_meta 修正，以及技能說明懸浮框修正）。

本頁開放第 1–3 關；第 4 關起鎖住並標「即將開放」。第 2、3 關仍依原本規則（前一關取得 1 星）解鎖。

升級後點角色技能，說明會以小框浮在技能圖示上方，可用再點一次、點空白處、Esc、移開滑鼠，或右上角 X 關閉，不會擋住底部的吸收／進化按鈕。

## 操作說明

1. 第一次打開會先到選關畫面。目前可開始第 1–3 關；其餘關卡顯示「即將開放」。開場有 4 張劇情（第 1 張會等載入畫面關掉後才由全暗漸亮）。第 1 波是教學關，可跳過。
2. 點左側拉霸櫃的轉動鈕，或按空白鍵轉動（有免費轉時鈕上會顯示「免費轉動」和 ×N；每波開場 2 次免費轉）。敵人從右側出兵、面向城門。場上最多 6 隻，多出來的進「後備 x/8」。打完第 3、6…27 波會開商店；第 5、10、15、20 波會出現封印碎片三選一。商店會等三選一或天賦頁關掉後再出現，關掉後戰鬥會繼續。
3. 撐過第 10／20／30 波各得 1 顆星；打完或城牆失守都會進入結算。按 T 開關天賦頁（10 頁）；按 L 切換語言；結算後可重試或回選關。
