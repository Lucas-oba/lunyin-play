# 輪印防線 試玩版

Godot 網頁試玩，不含原始碼。來源版本：天賦 v4 定稿基礎 `08978b8`（含 `88f0d8f`、`b1ed45f`、`1990578`，不含階段 4），再加上開場漸亮修正（`b4ff23d`）、商店流程修正、敵人朝向修正（`93f1767`＋`60e2372`）。不含 50 關／選關／結算／商店能力卡，也不含尚未完成的邪教徒重新出圖。

## 操作說明

1. 第一次打開會播放 4 張開場劇情（第 1 張會等載入畫面關掉、畫面出現後才開始由全暗漸亮，亮完才出短句；漸亮中點擊或按鍵會先亮到底，再按一次才換下一張。可按「跳過」或 Esc 整段跳過；之後可在語言選單重看）。第 1 波是教學關，一步一步教轉動、連線召喚、吸收進化、點天賦（也可跳過）。
2. 點左側拉霸櫃的轉動鈕，或按空白鍵轉動（有免費轉時鈕上會顯示「免費轉動」和 ×N；每波開場 2 次免費轉）。敵人從右側自動出兵、面向城門。場上最多 6 隻，多出來的進拉霸櫃下方「後備 x/8」，有人倒下會依序補上；後備也可拿來吸收。後備滿時，最舊的那隻會換成 +20 金。打完第 3、6…27 波會開商店（第 30 波不開）；看天賦或選碎片時，商店會等你關掉再出現。
3. 畫面右欄底部會一直顯示目標「守住 n/30 波、收集 n/4 片」。按 T（或點上方天賦書）開關天賦頁，10 頁天賦都可點，綠寶石點滿會亮；按 L（或右上語言鈕）切換語言；城牆失守後按 R 重來。
