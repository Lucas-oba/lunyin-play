# 輪印防線 試玩版

Godot 網頁試玩，不含原始碼。來源版本：`ce27440`＋開場漸亮（`1990578` 的改動，不含尚未驗收的天賦 v4）。開場 4 張劇情圖會由全暗慢慢亮起，亮完才出現短句。

## 操作說明

1. 第一次打開會播放 4 張開場劇情（每張由全暗漸亮，亮完才出短句；漸亮中點擊或按鍵會先亮到底，再按一次才換下一張。可按「跳過」或 Esc 整段跳過；之後可在語言選單重看）。第 1 波是教學關，一步一步教轉動、連線召喚、吸收進化、點天賦（也可跳過）。
2. 點左側拉霸櫃的轉動鈕，或按空白鍵轉動（有免費轉時鈕上會顯示「免費轉動」和 ×N；每波開場 2 次免費轉）。敵人從右側自動出兵。場上最多 6 隻，多出來的進拉霸櫃下方「後備 x/8」，有人倒下會依序補上；後備也可拿來吸收。後備滿時，最舊的那隻會換成 +20 金。
3. 畫面右欄底部會一直顯示目標「守住 n/30 波、收集 n/4 片」。按 T（或點上方天賦書）開關天賦頁，按 L（或右上語言鈕）切換語言；城牆失守後按 R 重來。
